# Blog Project

A simple Blog CRUD Application developed using PHP and MySQL as part of the ApexPlanet Web Development Internship.

## Features

- User Registration
- User Login
- Create Blog Posts
- View Blog Posts
- Edit Blog Posts
- Delete Blog Posts
- Logout

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- Git & GitHub

## How to Run

1. Start Apache and MySQL in XAMPP.
2. Place the project folder inside the `htdocs` directory.
3. Import the database into phpMyAdmin.
4. Open your browser and visit:
   http://localhost/blog_project/
